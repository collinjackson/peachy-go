# peachy-go

A Go client for [Peachy](https://pchy.app): the library (package `peachy` at
the root), the `peachy` command line, and `peachy daemon`, which answers
signal-cli-rest-api's HTTP API so chat bots run on Peachy. mautrix-peachy (the
Beeper bridge) imports the library. MPL-2.0.

This is an independent open-source project, not part of the Peachy product.

## Ground rules
- **Peachy's protocol comes only from
  [peachy-protocol](https://github.com/peachysocial/peachy-protocol)** (MIT):
  its protos, MLS engine, docs and fixtures, at `peachy-protocol.commit`.
  Only `generate.sh`'s output (`pb/`, `include/`) is copied in. Don't rely on
  any rpc, field or behavior it doesn't publish.
- **Don't copy AGPL code in** (mautrix-signal, mautrix-peachy's connector):
  this repo is MPL-2.0.
- **Don't write to Peachy's systems** beyond what a normal user's device does.
- **Test against your own account** or a local Peachy server, never someone
  else's account.

## Layout
- `device.go` (sign-in, linking, mailbox, sending), `lane.go` (reactions,
  edits, deletes, receipts), `store.go` and `storewrite.go` (the encrypted
  account store), `rpc.go` (Connect calls), `attachment.go` (sealed files),
  `state.go` (`device.json`), `mls.go` (cgo over peachy-protocol's
  `include/peachy_mls.h`, linked as `-lpeachy_mls_cabi`). `pb/` and
  `include/` are generated by `generate.sh`; never edit them by hand.
- `cmd/peachy/`: the command line (`main.go`) and the daemon (`daemon.go`).
  Keeps received messages in `messages.jsonl`, the
  daemon's timestamp map in `daemon-ids.jsonl`, and holds an flock so two
  commands never share the MLS state.
- `docs/`: `cli.md`, `bots.md`.

## Conventions
- `./build.sh`, then `gofmt`, `go vet ./...`, `go test ./...`, with
  `CGO_LDFLAGS=-L$PWD/target/lib`. The fixture tests replay peachy-protocol's
  fixtures (`target/peachy-protocol`, or `$PEACHY_PROTOCOL`).
- `go test -tags testissuer ./...` adds tests that play a group's other
  member (`testissuer.go`), against an engine built with
  `PEACHY_FEATURES=peachy-mls-cabi/test-issuer ./build.sh`. Never ship that
  engine.
- When peachy-protocol moves: follow its `docs/CHANGELOG.md` "Do" lines,
  update `peachy-protocol.commit`, run `./generate.sh`.
- Commit subjects start with a verb (`Add`, `Fix`, `Update`, `Remove`).
